Generated by `node scripts/wordlist-diff.mjs` (do not edit by hand). The old list is read from the git tag `live-before-upgrade` (`data/words.js`); ENABLE from `data/enable1.txt`. Both are run through the same `engine.js`, with nothing hidden (the counts below include words the new site hides by default; see the last section).

### What this means for the Wordle Solver (plainly)

The old list had **12,578** five-letter words; ENABLE has **8,636**. The solver will now recognize and suggest **fewer** words. Neither list is Wordle's own answer or guess list, so the solver has always been able to suggest words the game would never use as an answer, and it can still miss words the game accepts. Returning visitors may notice that some words they used to see (for example British spellings and many obscure words) no longer appear.
