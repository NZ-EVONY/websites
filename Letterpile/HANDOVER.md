## 1. What this is

Letterpile is a live static site at **https://letterpile.app**: in-browser word-game tools
(unscrambler, scrambler, combiner, tile-game finder, Words With Friends finder, Wordle, anagram,
jumble, crossword, Text Twist; Phase 4 added letter hive, word grid, letter box, multi-board,
word ladder, hangman, cryptogram, rhyming words and syllable counter, listed in `config/nav.json`), 12 guides, four hubs and 694 generated word-list pages, built from
the public-domain ENABLE word list. It is run by an independent publisher in New Zealand (always
say it that way; never use a personal name). Contact: `nz@letterpile.app`. American English.

Hosting: Cloudflare Workers **static assets only** (Worker name `letterpile`, `wrangler.jsonc`,
routes `letterpile.app` and `www.letterpile.app`; `www` 301s to the apex). No server code, no
database, no analytics, no ads yet.

  `login`, `whoami`, `secret`, `kv`, `r2`, `d1`, `tail`, `rollback` or `delete`. Never read `.wrangler/`.
- **Work only inside `Letterpile/`.** Never touch the sibling project folders.
- **Git identity:** commit only as `NZ-EVONY <221470641+NZ-EVONY@users.noreply.github.com>`,
  set repo-locally (`git config user.name` / `user.email`). No `Co-authored-by`, session or
  "generated by" trailers, and no AI wording in commit messages. The repo is public: every commit is
  published.
- **No personal names anywhere** (pages, docs, commits, JSON-LD). The JSON-LD author and publisher
  are the Organization "Letterpile". `tests/build/identity.test.mjs` enforces this on the built
  pages; it fails on the owner's surname, the other site's domain, "AI-assist" and `style=`.
- **No AI-assistance wording on any page.**
- **Don't push to `main`, force-push, rewrite history or open pull requests** unless the owner asks.
- Never claim "official", "tournament", "valid in Scrabble" or "accepted by" any game. No
  "Scrabble" in titles, H1s or descriptions. No "cheat".
- **No third-party requests** from pages (no web fonts, CDNs or analytics). The only exception is
  the user-initiated "Look up definition" call to the Free Dictionary API, with its disclosure line.
- **Ads stay off.** Only the marked integration points (CMP, AdSense, ad-slot partials); no ad code.
- **CSP:** exactly one inline script, `HEAD_SCRIPT` in `src/templates/layout.mjs`, whose SHA-256 is
  written into `public/_headers` by the build. No inline `style=` attributes.
- **`public/` is generated.** Change sources, run `npm run build`, and commit `public/` and
  `public-manifest.json` with the change. Never hand-edit `public/`.
- Facts in copy come from the word list at build time (`ctx.*`) or are verified; never typed from memory.
- Don't change, without the owner asking: `data/` (ENABLE list, checked by SHA-256),
  `src/assets/engine.js`, `src/assets/worker.js`, `scripts/pagegen.mjs`, `content/affixes.json`,
  `config/quality.json`, URLs, titles, H1s and meta descriptions.
- Report in three buckets: **VERIFIED** (ran it, quote the output) / **IMPLEMENTED, NOT TESTED** /
  **NOT VERIFIED** (say why). Never say "all tests pass" unless you just ran them.

## 5. Working on it

```
cd Letterpile
npm ci
npm test                 # build + unit + build-output tests (expect 62/62)
npm run regression       # deep links and old URLs
npm run test:e2e         # Chromium: axe light/dark, keyboard, CLS, ad placement, 360px, workers, privacy
npm run lighthouse       # mobile; pass URLs after "public <label>" to choose pages
npm run check:contrast   # every text style and input border, light/dark, 360/1280px
npm run check:deploy     # pre-deploy gate
npm run dry-run          # wrangler deploy --dry-run
npm run serve            # http://localhost:8788
node scripts/screenshots.mjs   # reports/screens/ at 390 and 1280px, light and dark
```

The browser tests and Lighthouse need Chromium (`playwright-core` is a dev dependency; set
`CHROME_PATH` if it isn't found). `reports/` is gitignored.

**Develop on a new branch made from `claude/letterpile-refresh`** (the deployed line), or on that
branch itself if the owner says so. Push only when the owner asks.

### Gotchas
- **Rebuilding changes every asset hash.** The committed `public/` was built on the owner's Windows
  PC, where files have CRLF line endings, so a Linux build produces the same content under different
  hashed file names (`style.<hash>.css` and so on) and touches every HTML page. If your change isn't
  meant to touch `public/`, discard that churn (`git checkout -- public public-manifest.json` and
  `git clean -fd public`). If it is, commit the rebuilt `public/` as normal; the owner deploys
  whatever is committed.
- The home page is the Unscrambler (`/`). It uses its own hero layout in `layout.mjs` (`page.hero`)
  and `src/templates/partials/home-extras.mjs`. Keep `<body data-page="unscrambler">`, the H1 and the ids.
- `HEAD_SCRIPT` must stay byte-identical unless you also accept the CSP hash change in `_headers`
  (the build does that automatically). Dark-by-default is done in CSS, not in that script.
- Elements with `hidden` must stay hidden; a global `[hidden]` rule and an e2e test guard this (the
  footer's "Privacy settings" link waits for a consent platform).
- Searches run in `src/assets/worker.js` through `UI.compute(...)`; never run heavy `Engine.*`
  searches on the main thread.

## 7. Facts worth knowing

- Word list: ENABLE, 172,823 words; 389 hidden by default (vulgar words and slurs; "Show all words"
  switch). The build fails if `data/enable1.txt` doesn't match the SHA-256 in `data/SOURCE.md`.
- Tile values shown are "commonly used" values, not a game's official ones.
- Theme: dark for everyone by default; light only via the toggle.
- Shared result links (`?letters=...`) are marked `noindex` by the head script and hide ad slots.
