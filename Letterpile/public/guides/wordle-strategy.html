Wordle Strategy and Letter Logic

Last updated: October 1, 2026

Daily five-letter puzzles reward a simple habit: use each guess to learn as much as possible, then use what you learned. This guide shows which letters are most common in five-letter words, how the colors work with repeated letters, and a worked example of a puzzle narrowing down. The numbers come from the 8,564 five-letter words in the open ENABLE list that Letterpile uses, not from the game's own answer list, which is smaller and mostly made of everyday words.

S tops the list because the word list includes many plurals, such as five-letter words made by adding S to a four-letter word. A puzzle that avoids plurals as answers will make S less useful than this table suggests, which is one reason to treat these numbers as a starting point.

A letter that turns yellow tells you it's in the word but not in that spot. Knowing where letters usually sit helps you guess where it belongs.

Opening guesses

A good first guess uses five different letters, mostly common ones, so every tile tests something new. Words such as SLATE and CRANE fit that description. There is no single best opener: some players prefer to test vowels, others common consonants. What matters more is the second guess, which should use the first guess's colors and still test new letters where possible.

Of the five-letter words in the list, 2,932 have a repeated letter. Repeated-letter words test fewer letters, so they are weaker as early guesses, but don't rule them out as answers.

How colors work with repeated letters

  • Green: right letter, right spot.
  • Yellow: the letter is in the word, but somewhere else.
  • Gray: the word has no more copies of that letter than the ones already shown green or yellow.

The third rule is the one that trips people up. Suppose the answer were SPEED and you guessed GEESE. The colors would be gray, yellow, green, yellow, gray. Two E's are green or yellow because the answer has two E's; the third E is gray even though E is in the word, because there is no third E. A gray tile on a repeated letter limits how many copies there are; it doesn't rule the letter out.

A worked example

Say the answer is SPORE (we pick it here only to compute the colors; the solver never knows the answer).

  1. Guess CRANE. The colors come back: gray, yellow, gray, gray, green. Using those clues, 86 words in the list still fit.
  2. Guess SPILT, which keeps the letters we know about in useful places and tests new ones. Colors: green, green, gray, gray, gray. Now 3 words fit.
  3. From there, pick the most familiar word among the few that remain. Everyday words are more likely to be answers than obscure ones.

You can replay this in the Wordle Solver: add each guess and tap the tiles to match the colors above.

If you want to check a worked example yourself, the Crossword Solver can show every word that fits a pattern of known letters, which is a quick way to see how many candidates a set of green tiles leaves.

Common traps

  • Repeating known-gray letters. Every letter in a guess should either test something new or confirm a position.
  • Fixing too early. When many words share four letters (for example, a run of words that differ only in the first letter), a guess that tests several of those first letters at once can save turns.
  • Ignoring yellow positions. A yellow letter can't be in the spot where it was yellow. Move it.
