Last updated: October 1, 2026

There are 571 words that start with EL in the ENABLE list, which is roughly 0.33% of the words Letterpile uses. The longest is ELECTROENCEPHALOGRAPHICALLY; the shortest is EL. The highest base score belongs to ELECTROENCEPHALOGRAPHICALLY (47 points), using commonly used tile values. 60 of them use no letter twice, which matters in games where every tile is separate.
