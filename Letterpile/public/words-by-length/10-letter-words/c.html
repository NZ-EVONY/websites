10-Letter Words Starting With C

Last updated: October 1, 2026

Counting only the ENABLE word list, 1,994 entries are 10-letter words that start with C. That is about 1.2% of the list. All of them have the same length, so they differ only in their letters. By common tile values the top scorer is CHIFFCHAFF (32 points); board bonuses aren't counted. Words with no repeated letter: 111. Different games use different dictionaries, so check your game's rules before relying on a word.
