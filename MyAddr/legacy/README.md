# legacy/

Old prototype, not deployed, not maintained, network-tool endpoints removed on purpose; history is in git.

`ip-prototype/` is the earlier "what's my IP" page that used to sit in `MyAddr/`. Its
`server.js` and `app.js` are now stubs: the port-check, ping, traceroute, WHOIS and
third-party IP-lookup code was deleted. `index.html` and `styles.css` are kept only as a
record of the old layout and palette. Nothing here is built, imported or published.
